连接 Zotero
保持 Zotero 打开，在“设置 → 高级”中允许此计算机上的应用与 Zotero 通信。
选择 Zotero 的 storage 或链接附件文件夹。每行一个路径。留空时只导入书目信息。
用逗号分隔，如：生育,婚育。留空时覆盖全部资料；大资料库建议先试点。


扫描 PDF 文字识别
使用 Windows 自带 OCR，仅为没有文字层的页面生成可检索片段，不修改原 PDF。识别文字可能有误，结果会单独标注。已处理页下次跳过。
建议先识别 20 页；大型扫描资料可分批继续。缺少语言包时请在 Windows 语言设置中安装。


本地语义检索
使用多语 E5 模型在本机计算。首次需要下载模型；不上传文献。模型和索引会占用额外磁盘空间。
导入或文件夹范围改变后请刷新语义索引。混合检索合并全文与语义排名，不生成论文结论。
