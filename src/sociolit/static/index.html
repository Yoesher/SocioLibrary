在期刊卡片中选择“修改来源”，或点击“添加期刊”。


如何接入一本期刊？
方式一：官网 RSS / Atom。在出版机构的期刊页面寻找 RSS、Atom 或“目录订阅”；复制实际订阅地址，在“添加期刊”里选择官网 RSS / Atom。填写期刊名称和地址，再点击“验证并保存”。频道刊名应与期刊对应；英文频道可填写英文刊名。普通期刊主页或邮件订阅页面不能当作 RSS。
方式二：Crossref。从期刊官网“期刊信息”找到印刷版或电子版 ISSN，选择 Crossref 并填入号码。例如 American Sociological Review 的 ISSN 为 0003-1224。无需 API 密钥。验证后会显示数据库实际返回的刊名，请核对；未收录会报错，不能保证所有中文期刊都有数据。
方式三：OpenAlex。同样使用 ISSN；需先在本机环境配置 OPENALEX_API_KEY，再重新打开软件。密钥不填在订阅地址里，也不提交到 GitHub。尚未配置时可先用 Crossref 或官网 RSS。
保存后点“立即检查”收集书目。桌面版在启动时检查当月是否到期；软件关闭期间不会自行运行，重新打开后补查。暂停只停止后续请求，已入库文献保留。RSS 仅覆盖频道当前保留条目，不能保证补齐全部过刊。
原有四刊可直接使用内置官网来源。社会学评论、人口学刊、中国社会科学仍需有效来源验证后启用；学校机构订阅不等于公开采集接口。全文请按原有机构权限在出版社或数据库阅读。
