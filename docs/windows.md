# Windows 桌面版

面向 Windows 10 / 11 x64；本轮不发布 macOS、Linux、ARM 原生或 32 位安装包。

0.5 新增“AI 文献阅读”：可配置自己的 OpenAI / ChatGPT API、多种兼容服务及本机模型，逐次预览选中片段并确认后再发送。密钥在 Windows 当前账号下加密，随原资料目录保留，升级快照包含加密配置。详见 [AI 配置和使用](ai.md)。

## 安装

从 [GitHub Releases](https://github.com/Yoesher/SocioLibrary/releases) 下载名称包含 `Windows-x64-Setup.exe` 的安装包。双击后安装到当前用户目录，开始菜单中启动 SocioLibrary。无需安装 Python、Node 或 Docker。

免安装版为 `Windows-x64-Portable.zip`，解压整个目录并运行其中的 `SocioLibrary.exe`，不可只拷贝 exe。建议放在较短的本机路径，避免 Windows 深层目录路径长度限制。免安装指程序无需安装，研究资料仍保存在用户资料目录，不会跟着 U 盘移动。

界面使用 Microsoft Edge WebView2。若机器尚未安装，请从 [微软官方页面](https://developer.microsoft.com/microsoft-edge/webview2/) 安装 Evergreen Runtime；软件不使用旧 IE 渲染器。安装包当前没有代码签名，可能显示来源未知；请核对官方发布来源和 SHA256SUMS，不应关闭系统安全保护。

## 第一次使用

1. 打开 Zotero，在设置 → 高级中允许本机应用通信。
2. 打开“资料与设置”，点击“测试连接”，选择存放 PDF 的 storage 或链接附件文件夹并保存。
3. 点击“同步 Zotero”。任务在后台运行，窗口内显示阶段；可继续全文检索。初次大型索引需要较长时间。
4. 如需要语义检索，下载本地模型，填写试点文件夹名称，再构建索引。语义和混合检索需要模型与完整索引。

## 资料、升级与退出

资料默认保存在 `%LOCALAPPDATA%/SocioLit`。文献原文件仍由 Zotero 管理。首次安装需设置 PDF 许可范围；升级会沿用已经保存的范围与语义试点，不需重复选择或导入。只更换程序时，已有模型和向量也不需重新下载或构建。

**升级步骤：**等待后台任务完成并关闭软件，运行新版 `Setup.exe`，安装完成后启动。安装器会识别旧版并沿用原安装位置和快捷方式选项；无需先卸载。0.3.1 起程序运行时，安装器会要求先关闭软件。免安装版可解压到新的程序文件夹启动，仍沿用同一个资料目录，不把研究资料放进程序目录。

**自动继承：**文献书目、全文与语义索引、阅读笔记与摘录、保存检索、OCR、期刊配置和更新状态、PDF 许可范围及试点设置均沿用原库。模型与原 PDF 留在原位置。使用 `--data-dir` 的自定义目录在桌面版成功加载后会被记住，下次普通启动继续使用；显式 `--data-dir` 优先于 `SOCIOLIT_DATA_DIR`，再优先于已记住的目录。目录记忆保存在 `%LOCALAPPDATA%/SocioLibrary/desktop-location.json`，不随程序覆盖。自定义磁盘失联时提示重新连接，不会悄悄切换到空库。

**升级前备份：**发现旧版本或首次识别旧库时，在资料目录 `backups` 下生成数据库和设置副本，SQLite 在线备份包含已提交的 WAL 内容。副本校验完成后才加载新版库；新版本和设置加载成功后记录版本。同一版本重启不重复备份。首次升级大库可能需稍等，并需额外磁盘空间；备份失败会停止初始化，原库不被新版改写。备份不重复复制模型和 PDF，也不代替定期异盘备份。副本不自动删除。

**恢复：**关闭软件及其他写入任务，先另存当前完整资料目录。使用 `backups` 中的副本恢复到一个新的资料文件夹，包含 `library.sqlite3`、原有 `preferences.json` 和（如存在）`desktop-version.json`；不要把旧库直接覆盖到仍运行的目录或混用旧 WAL/SHM 文件。用桌面程序的 `--data-dir` 指向该新目录，模型可从原目录另行复制；PDF 仍使用原许可路径。后续普通启动会记住新目录。不建议降级；0.3.1 起检测到比程序更新的版本记录时会停止启动。

卸载不会删除文献索引、模型、本地设置或升级备份。另行备份整个资料目录前，关闭软件和其他写入进程。不要同时启动旧版脚本执行导入。

软件关闭时本轮后台工作会中断；已提交的文件和向量保留，下次可以继续同步或构建。模型下载受网络影响；失败后请根据提示重试。下载不会上传文献。

桌面软件启动时按来源检查本月是否已更新；只有软件启动并联网时运行。不是后台常驻服务。已有命令行定时任务仍可继续使用，桌面版不会自动新增系统任务。

## 软件内检查与一键升级（0.4）

0.3.x 尚无此功能，需先安装一次 0.4.0。之后打开“软件更新”，可检查版本、阅读说明，点击“下载并升级”。软件启动及运行期间按需检查，每 24 小时最多自动联网检查一次；失败后至少间隔 1 小时再自动尝试，可关闭自动检查，手动检查仍可用。关闭软件后不运行检查，不创建系统常驻服务。

下载只访问本项目官方 GitHub 版本及其官方 HTTPS 文件主机，不上传论文、笔记、检索记录或库配置。仅接受更高的正式版本及精确命名的 Windows 安装包；缺少大小或 SHA-256 信息时不安装。网络中断会有限重试，重新点击下载可继续已有部分；文件完成核对后才允许安装。GitHub 无法连接或限流时可继续使用原软件，不改用第三方下载镜像。

安装版默认在下载后自动关闭、安装并重新打开原资料库，也可点击“下载后稍后安装”，等待自己点击“安装并重启”。下载期间可继续检索；尚未保存的笔记、资料设置、导出对话框、检索或后台任务结束前不自动安装。安装交接持有原进程句柄，确认原程序完全退出后才运行安装器。安装不重启电脑，Windows 自身的安全确认不会被绕过。

免安装版会明确显示“下载并升级为安装版”，将安装到已有安装位置或当前用户的默认程序目录，再打开原资料目录；原免安装目录不会被自动删除。源码及浏览器模式可检查与下载，但不允许自动退出开发进程并替换程序。

更新设置位于资料目录 `software-update.json`，随下一次版本升级的数据库与设置备份保留；下载缓存及交接结果在 `%LOCALAPPDATA%/SocioLibrary/updates`。软件内显示上次安装结果，可点“查看更新记录”打开版本目录中的交接结果和安装日志。安装失败时会尝试重新打开原程序；窗口未能关闭则取消交接，继续保留当前软件及编辑功能。不会把软件安装失败当作新库初始化成功。SHA-256 用于核对官方发布记录，不等同于代码签名；当前安装包仍未签名。

## 阅读清单、最近检索与导出（0.4）

检索结果下方可设置待读、在读、已读，并加入收藏。在“阅读清单”按状态、收藏或归档筛选，归档可恢复。清单快照独立于 Zotero，同步移除条目后仍保留，并提示原条目不可用；不自动写回 Zotero。列表最近展示 500 条。

“检索与笔记”中可重用最近 20 次提交的检索，包含关键词、检索方式、作者与年份，重复条件只保留一次；可以清空。构建索引时若写锁繁忙，本次历史记录可跳过，全文检索继续可用。

桌面版“导出笔记与摘录”导出全部未归档笔记，包括超过界面 500 条上限的记录。输出为本机 Markdown，笔记和摘录以文本块保留，附已有题名、PDF 页序、已记录的文件页标签及 OCR 提示；不填补缺失的文献信息，不是自动生成正式参考文献。导出不是完整资料库备份。文件仅写入你选择的本机位置，不会自动公开。

## 构建

开发者使用 Windows x64、Python 3.11、Inno Setup 6。先从官方 PyTorch CPU 索引安装 CPU 版 torch，再安装 `.[desktop,semantic,dev]`，执行 `scripts/build-windows.ps1`。二进制只包含程序、依赖、公开配置和许可；不包含真实资料或模型权重。

GitHub 的 Build Windows desktop 工作流构建安装版和免安装版，检查打包后的本地服务、静态资源、PDF DLL 和语义运行组件。完整模型检索效果和不同 Windows 版本仍需用户环境验收，不将冒烟检查当作全部功能评测。

## OCR、检索和笔记（0.3）

在“资料与设置”检测 OCR 语言，选择已安装的中文或英文语言。Windows 没有所需 OCR 组件时需自行在 Windows 语言设置中安装，不会自动下载组件。每次默认 20 页，可设置 1–100 页；已处理的页面下次跳过，换语言不会自动重做已缓存页面。只处理登记在资料库且位于 PDF 许可范围内、存在无文字层页面的 PDF。临时页面图像识别后删除，原 PDF 不改写。

OCR 输出可能存在错字、缺字和阅读顺序问题。结果页标注为“OCR 识别文字”，PDF 页序仍可定位。识别完成后，如需语义检索，请刷新语义索引。无字空白页也会记为已检查，避免重复识别。PDF 内容变化后必须先同步 Zotero，旧 OCR 缓存随旧文件索引移除。

执行检索后输入名称保存；“检索与笔记”内保存的是检索条件，不是永久冻结的结果。点击重新检索会使用当前资料库，因此结果可能变化。

可从结果写笔记，保留来源片段、文献题名、PDF 页序及原始片段类型作为快照。也可独立写笔记、编辑、归档或恢复。Zotero 条目删除后笔记保留；快照可能早于当前文件，引用前仍需核对。列表展示最近 500 条。

“期刊动态”增加 RSS 设置。只接受公开 HTTPS，不接受账号、认证令牌或 Cookie；保存前需返回真实 RSS/Atom，频道标题包含所选期刊名。失败不替换原订阅，验证成功才启用。暂停自定义 RSS 不发送网络请求。云端公开配置不包含个人配置的 RSS。已有机构阅读权限不自动等于自动采集权限。

《社会学评论》《人口学刊》《中国社会科学》目前仍无已实测可用的直接自动源；本轮交付的是可配置、可验证的接入通道，不能据此声称三刊已接通。
