# 0.9 完整界面风格

在“资料与设置”选择整套风格，直接预览，满意后“保存风格”；“取消预览”恢复上次保存的选择。配色、显示密度和动画单独选择，同一配色也有三套不同的界面结构。首次没有风格设置时使用 Apple，不重写原设置文件。

| 风格 | 导航与工作区 | 阅读与控件 | 动效与图谱 |
| --- | --- | --- | --- |
| Apple · 轻透工作台 | 悬浮圆角侧栏、轻透置顶工具栏、选中实色胶囊 | 清楚的白色阅读纸面、轻阴影、圆角输入框与页码胶囊 | 短距离淡入、圆形节点 |
| Windows · 高效工作区 | 停靠分组导航、左侧选中标记、边框工作区 | 较方正的紧凑控件、分层卡片、正文线索强调边 | 横向快速进入、横向圆角矩形节点 |
| Material · 灵感空间 | 窄导航轨、图标与标签上下排列、舒展标题 | 大圆角色调容器、胶囊按钮、柔和层次 | 舒展的位移与缩放、圆角矩形节点 |

检索、阅读清单、批注、推荐比较、图谱、AI 及维护设置共用风格系统。切换只变外观，不重建当前页面，不清空检索结果、选择或表单。图谱更新节点样式时保留选中与视角。聚焦同心布局把中心与邻居分为两层。

## 可读性与无障碍

- 内容与导航分层，透明效果仅用于 Apple 导航及工具栏，摘要和命中页仍为实色内容。
- 墨夜与跟随系统配色保留；高对比模式使用实色工具栏及清楚的边界。
- 紧凑密度缩减卡片、导航和工具栏间距，保留所选风格。
- 风格单选组支持方向键、Home、End；提供焦点标记。
- 系统减少动画时不播放页面及风格切换动画，减少透明度时去掉模糊。
- 小窗口折叠为横向可滚动导航；阅读比较表保留自身横向滚动。

## 官方参考与实现边界（2026-11-11）

- [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：学习导航、控制层与内容层的区分和透明材料的克制使用；[Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars)：分组导航和当前项。
- [Fluent 2 Material](https://fluent2.microsoft.design/material) 与 [Layout](https://fluent2.microsoft.design/layout)：学习分层表面、停靠导航、清楚的选中标记和间距。
- [Material 3 Shape](https://m3.material.io/styles/shape/overview-principles)、[Typography](https://m3.material.io/styles/typography/applying-type) 与 [Motion](https://m3.material.io/styles/motion)：学习角色化形状、文字层级与不同的进入节奏。

三套均为本项目自行实现的 Windows WebView 界面，不是系统主题引擎，也不提供原生 Liquid Glass、Mica 或 Acrylic。没有引入专有字体、SF Symbols、平台品牌图片或运行时 CDN。Windows 使用本机系统字体，所有样式、图标、脚本及图谱引擎随安装包离线提供。

## 设置兼容

本机 `preferences.json` 新增 `design`（`apple`、`fluent`、`material`），原 `theme`、`motion`、`density` 和 `auto_embed` 字段沿用。没有 `design` 的旧设置默认 Apple；旧客户端保存四个原字段时保留已选风格。外观保存只合并相关字段，PDF 许可目录、核心文件夹及其他未知设置继续保留。无效值会在写入前拒绝。

界面预览不保存设置；取消不会改写文件。覆盖安装和升级前快照机制沿用，个人资料、PDF、索引、模型、批注、笔记和密钥留在本机。
