# 0.7：跨语言检索、资料整理和文献关系

## 中文查询如何找到英文文献

默认“智能检索 · 中英互搜”结合原词、内置社会学中英术语和本机多语言语义检索。术语表是离线查询扩展，不能翻译任意句子；没有模型时仍能覆盖表内术语。英文题名候选与其他候选交错展示，排序是阅读线索。

在“资料整理”点击“建立 / 继续全库书目语义索引”。首次需先在“资料与设置”准备本地 E5 模型。每篇书目的题名、摘要和标签生成一个向量，覆盖全部已导入书目；不会为全库 PDF 重新计算全文向量。中断后可继续，未变书目复用；只改变 Zotero 更新时间而未改变检索文字时也复用。

这与原有全文语义试点分开：书目层帮助找到文献，PDF 试点帮助找原文片段。智能检索优先采用完整、有效的全库书目语义；尚未建立时可使用已有全文试点，并明确显示本次覆盖范围或未参与原因。单独选择“语义检索”“混合检索”仍按全文试点处理。全文字词检索覆盖全部已导入片段，不会自动翻译。

书目语义命中显示书目信息，不虚构 PDF 页码；返回全文后仍需核对原文。全库书目索引不意味着已读过或理解全部论文，也不是对所有查询相关性的保证。

本机检索模型为 [multilingual E5 small](https://huggingface.co/intfloat/multilingual-e5-small)，以查询和文档前缀编码。本软件的跨语言整合和术语表为独立实现，未复制其他项目代码。

## 新文献如何整理

日常步骤：打开 Zotero，完成它自己的同步，再在软件中点击“同步 Zotero”或“资料整理 → 同步并按设置整理”。软件不是常驻 Zotero 监视器，关闭软件时不会替你整理文献。

1. 软件通过本机只读接口取得完整快照，规范化书目信息，以记录指纹、PDF SHA-256 和批注指纹判断变化。未变 PDF 与向量复用，新增或变化内容才更新。
2. 如已建立全库书目索引或文件夹全文试点，且“同步后自动补齐”开启、本机模型已就绪，同步任务会增量补齐它们。首次建立由使用者启动；不自动下载模型、不自动处理整个全文库。失败时保留已完成的同步和向量，下次可继续。
3. 源记录不再返回时，清理其过期检索片段、向量和附件关联；保留独立阅读笔记、比较表及人工关系的来源快照。软件不删除或改写原 PDF，不直接编辑 Zotero 数据库。
4. “重复文献候选”以相同 DOI 或规范化题名列组，最多展示40组，每组最多20条。只是待核对线索，不自动合并；需要合并时到 Zotero 人工核对，再同步。

这些步骤由本地软件执行，不依赖维护者在线，也不需要聊天 API。检索用的 E5 模型在本机运行；ChatGPT 等接口是可选的生成服务。

“AI 阅读与连接”管理的连接共用于阅读、比较和整理。先在检索结果选择片段，再到“资料整理 → 整理已选片段”，可以请模型归纳主题、研究问题、理论、方法与对象。沿用完整预览、逐次同意、一次请求、不自动重试和来源快照；结果保存为待核对 AI 笔记，不批量改写 Zotero 标签。不能把一次片段整理当作通读全文或自动全库分类。

## 文献关系图谱

参考 [Obsidian Graph view](https://obsidian.md/help/plugins/graph) 的节点、局部图、缩放和点击查看方式，独立实现本机 SVG 图谱，没有嵌入 Obsidian 或复制其专有代码。

- 在检索结果点击“查看文献关联”，或进入“文献关系图谱”按题名、标签浏览。每次显示30、50或80篇，避免把数千条记录堆叠；题名检索支持术语表扩展。
- 自动线索包括共享 Zotero 标签、题名字词候选、已有完整书目索引的语义邻近，以及同一比较表。它们均不表示已证实的引用、理论一致或因果关系；可统一隐藏自动线索。
- 人工关系包括相关、理论对话、结论分歧、方法可比、本人确认的引用。引用方向为文献一指向文献二，详情会区分引用与被引用。可添加说明，归档、恢复，不直接删除；原文失联后保留关系快照。
- 点击节点查看完整题名和关系理由；拖动节点或背景，滚轮及加减按钮缩放。SVG支持键盘聚焦、Enter/空格打开节点、方向键移动。也可使用文献列表查看。
- 中心视图扩展人工邻居、标签邻居和已有书目语义邻居。没有完整书目索引时不会下载模型、临时计算或调用云端生成连线。

人工关系保存在 `literature_links`，书目向量保存在 `catalog_vectors`，均在本机资料库内并随升级快照保留。图谱只读展示自动候选，不把它们写成永久“真实关系”。图谱并非已验证的引文数据库。

## 主题和动效

“资料与设置 → 外观与交互”提供竹青、海盐蓝、暖纸、墨夜、紫藤、松石、玫瑰、高对比八款主题及跟随系统；轻柔淡入、简洁快速、关闭动画三档；舒展或紧凑密度。先预览，点击保存后下次沿用。系统要求减少动画时优先关闭动画，不运行持续力导向动画。

外观与自动整理设置保存在原有 `preferences.json`，与 PDF 许可目录、文件夹范围相互保留，并纳入既有升级备份。修改主题不会调用 AI。模型、PDF、笔记、API 密钥不随程序升级包公开。
