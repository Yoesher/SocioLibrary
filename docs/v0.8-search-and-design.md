# 0.8 文献检索与桌面交互

## 结果按论文组织

原来的片段列表可能让参考书目或作者单位排在正文前面，也没有真正的后续结果分页。现在桌面使用 `/api/search/papers`：每篇文献只占一张卡片，顺序为论文摘要、与查询的关系、原文命中页。旧 `/api/search` 保留，供已有调用者兼容。

- 摘要优先使用来源书目中的完整摘要；没有摘要时，只在已索引的 PDF 前三页寻找明确的“摘要—关键词”段落，并标注提取页和待核对。找不到就显示暂无摘要，不把正文、参考书目或 AI 生成内容冒充作者摘要。
- 关联说明列出实际命中的题名、摘要、正文词语，并摘出摘要中的对应句子。它是可检查的本机检索说明，不自动付费调用云端模型，不推断论文没有提供的结论。
- 字词检索从全部命中中按文献取候选，不再先截取 100 个片段再凑结果。每篇最多展示三个不同原文页；参考书目、作者单位、编辑信息等不作为主要正文证据。原始文字、页码和索引仍保留。
- 同一次检索的结果保存在本机内存快照中，上下翻页不会重复计算模型或重新排序。快照绑定查询和筛选条件，20 分钟后、同步或片段数量变化时要求重新检索。最多保留六次检索，不写出私有检索缓存。
- 字词结果的数量是本次匹配的文献数量。语义检索仍有最多 100 个候选及已建立索引范围的限制；不会把这些候选数量说成完整语义召回数量。
- 结果顶部和底部都有翻页控制，支持每页 10、20、30 篇。详情页独立于搜索结果页，查看图谱中的论文后可返回，保留原检索页和滚动位置。

## 在 Zotero 打开原文

核验 [Zotero 官方协议实现](https://github.com/zotero/zotero/blob/main/chrome/content/zotero/ZoteroProtocolHandler.mjs) 后，原文主入口使用 `zotero://open-pdf/library/items/附件键?page=实际页序`，由桌面程序交给 Windows 注册的 Zotero 客户端。传入的附件和页必须存在于本机索引；原生桥不接收任意网址或文件命令。搜索、推荐、批注、比较及 AI 来源中的原文链接共用这个入口。

当前导入器读取 Zotero 本机个人库 `/users/0`，不猜测群组库编号。其他来源和无法映射的附件仍提供本机 PDF 预览。PDF 实际页序、文件页标签和刊物印刷页码分开标示；页码链接使用实际页序。Zotero 是否使用内置阅读器遵循用户的 Zotero 阅读器设置。

## GitHub 调研与选型（2026-11-11）

| 来源 | 核验到的能力 | 本项目的取舍 |
| --- | --- | --- |
| [Cytoscape.js](https://github.com/cytoscape/cytoscape.js) / [官方布局文档](https://js.cytoscape.org/#layouts) | 完整图模型、Canvas 渲染、内置同心及 CoSE 布局、选中、邻居集合、拖动和缩放；MIT | 取代简陋的手写 SVG 力计算。固定 3.35.0，自带离线文件、许可和摘要校验；无运行时 CDN。 |
| [force-graph](https://github.com/vasturiano/force-graph) | Canvas 与 d3-force，节点/边悬停、点击、缩放及拖动示例 | 学习按选中文献突出关联和弱化背景的方式；本版没有复制或引入其代码。 |
| [Sigma.js](https://github.com/jacomyal/sigma.js) | 面向大量节点的 WebGL 渲染，配合 Graphology | 当前图谱上限 80 篇，优先易读标签和较低的 Windows 图形要求；暂不引入额外图模型和 WebGL 依赖。 |
| [Zotero 官方源码](https://github.com/zotero/zotero) | 阅读器协议把 URL 的 page 减一变为内部 pageIndex | 仅核验公开协议并自行实现链接；未复制 AGPL 源码。 |

本版布局参考 Apple 官方的 [侧栏](https://developer.apple.com/design/human-interface-guidelines/sidebars) 与 [搜索框](https://developer.apple.com/design/human-interface-guidelines/search-fields) 指南：分组侧栏、系统字体、清楚的内容层次、简洁结果和单独详情区域。实际配色、图标和 CSS 为本项目设计；没有使用 Apple 字体、SF Symbols 或品牌图片，也不声称这是原生 macOS 软件。

图谱默认最多 15 篇，可选 30、50、80 篇。提供同心关系与自由网络布局，选中时突出邻居及连线，侧栏列出完整题名和关系依据；支持文献列表键盘操作。本人建立的关系、共同标签/词语、同一比较表和语义线索分别保留来源说明。自动连线不能当作真实引用。
