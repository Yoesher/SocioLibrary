# 0.10 动态文献关系图谱

图谱是本地文献之间的探索视图。进入时优先展示有联系的书目；输入主题可以缩小范围。从一篇文献逐步展开，比一次铺满整库更容易核对线索。

## 一次探索

1. 在“文献关系图谱”输入主题，或从检索结果进入“查看文献关联”。
2. 悬停查看完整题名与作者；单击选中后，相邻文献及连线突出，右侧显示可核对的关系依据。
3. 点击“展开8篇关联”，把尚未展示的候选加入原画布。原有节点和视角保留；动态网络会围绕新增文献舒展。没有更多候选时保留原视图并明确提示。
4. 拖动节点会固定它的位置；单击不会误固定。可以取消固定、释放所有固定，或暂停动态。
5. 双击文献或点“摘要与原文”进入阅读；返回后继续原图谱。原文入口仍由桌面桥交给 Zotero 客户端。
6. 图谱自己的返回/前进恢复最多12步本次会话记录，包括节点位置、视角、选中文献、固定状态、主题和来源筛选。

单视图上限80篇，每次展开最多8篇；到达上限后，“以此为中心”可以开启下一段探索。概览是候选抽样，不能当作全库关系的完整统计。

## 布局与显示

- **动态网络**：本机受力运算，关联文献相互牵引、节点互相避让。交互后短时间运行，稳定后停下；可以随时暂停，不做无意义的持续漂移。
- **同心关系**：围绕中心文献排列；适合查看直接关联。
- **年代脉络**：按来源年份从左至右排列，未注明年份单列；节点标题附年份。固定节点保持原位，可先释放固定再重排。
- **概览**：显示全图、当前视野与选中节点，点击定位；键盘回车可适合全图。
- **图内定位**：按本图题名、作者或标签查找，直接聚焦；键盘列表提供相同的选择入口。
- **来源筛选**：本人确认、标签与词语、本机语义、比较表分别查看；可隐藏孤立文献。被筛选隐藏的选择保留，允许一键显示该文献。
- **沉浸探索**：扩展软件内工作区，退出或按Esc返回；切到文献详情再返回时恢复。不是系统全屏，也不改变 Windows 设置。

颜色只区分连通分组，大小对应邻居数量，不代表论文质量或理论流派。缩小时标签渐隐；聚焦、悬停、图内定位和详情面板保留可读入口。Apple、Windows、Material 与深色配色沿用。

系统减少动画或软件关闭动画时，不播放布局过渡和受力动画；图谱仍可拖动、固定、展开、筛选和阅读。页面进入后台或离开图谱时停止动态计算。位置、固定与探索历史仅存在本次打开的内存中，历史是会话快照；同步资料后可以回到概览重新读取。本版不声称已保存永久图谱布局。

## 线索与资料边界

- 实线是本人建立的关系，“引用”必须由本人核对原文后建立；归档、恢复沿用版本冲突保护。
- 自动线索分别来自共享标签、题名与摘要共同词语、已经齐备的本机书目语义向量，以及同一文献比较表。每条保留来源和理由；不代表真实引用、因果或结论一致。
- 没有连线时显示实际状态，不补造关系。初始和主题概览按已有关系选择，题名排序只在最多240篇近期候选中做有界比较；不会计算整库两两相似度。
- 一次展开在最多80篇中心候选中选择未展示文献；词语推荐有300篇候选限制，已有书目语义只复用当前索引。候选耗尽不等于整库没有其他相关研究。
- 展开、筛选、固定和历史返回不写入 Zotero 或文献数据库，不读取 Zotero 数据库，不发送论文到云端，也不自动下载、加载或调用新的AI模型。
- 原有人工连线、批注、笔记与比较表沿用；公开测试使用合成资料，个人书目副本和界面检查截图留在本机。

## 实现与官方参考

使用本地固定的 [Cytoscape.js 3.35.0](https://github.com/cytoscape/cytoscape.js/tree/v3.35.0) 渲染，同一画布增量添加节点和连线。参考其[动画与视口API](https://js.cytoscape.org/#cy.animate)、[拖动与用户事件](https://js.cytoscape.org/#events/user-input-device-events)，以及 [Obsidian 图谱指南](https://obsidian.md/help/plugins/graph) 中的局部探索、悬停突出、来源筛选和概览思路。交互、受力运算、历史与样式为本项目实现，没有复制 Obsidian 代码，没有新增运行时 CDN 或图谱依赖。

受力计算最多30次每秒、210步后停止；80篇与有界连线限制控制本机计算量。来源筛选和纯图运算有离线测试；80节点重叠、固定锚点及数值有限性有确定性测试。新接口 `POST /api/graph/expand` 受本机令牌、来源校验、资料任务占用与容量检查保护；自动线索ID按来源、端点和依据生成，增量合并不重复加入同一线索。
