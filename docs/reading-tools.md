# 推荐、Zotero 批注与结构化文献比较（0.6）

这三项功能以本机资料和可核对的来源为基础。推荐、批注同步和手工对照不需要 AI 账号。只有选择 AI 提取、预览并逐次确认后才调用已有 AI 连接。

## 相似文献推荐

在检索结果点击“相似文献”，或在推荐卡片中继续以该篇为参考。默认比较已导入文献的题名、摘要及标签，不需要下载模型。候选来自 FTS 书目片段与相同标签，最多 300 篇；最多查询 32 个字词和 32 个标签、读取 1200 个 FTS 命中及 100 个标签候选。按加权字词向量排序并展示共同文字或标签，不随机补足列表。同 DOI 或规范化题名的种子和重复候选会被排除，只影响推荐展示，不合并或删除文献。

切换“已有本机语义索引”可复用 E5 模型与已经完成的索引，以参考文献题名、摘要前部和标签寻找相近片段。范围沿用语义试点设置，不自动扩大到整库、不自动构建索引；缺少、过期或未完成时明确报错。模型 token 上限会影响输入，排序仍是检索线索，不证明引用关系、理论一致或研究质量。完整库召回率及社会学相关性尚需人工评测。

点击候选的“查看片段并加入对照”，默认列前 20 个片段，也可在本篇内查找方法、数据等关键词。原有 AND 关键词规则继续适用。

## Zotero PDF 批注

保持 Zotero 打开并开启本机通信，点击“同步 Zotero”。个人库完整元数据快照中的 PDF 批注会导入本机独立表，保留摘录、个人评论、类型、颜色、标签与位置。不读取或复制 Zotero 数据库、不写回 Zotero、不获取图像／手绘本体；EPUB、网页或未能关联 PDF 的批注不在本版范围。

批注的 `annotationPosition.pageIndex` 为零起算位置，转换成 PDF 页序；`annotationPageLabel` 单独保留，不把罗马数字或印刷页码猜成物理页序。位置无效或 PDF 不可用时不提供虚假的页链接。批注文字可在全文中检索；摘录和个人评论分别切分，每个评论片段明确标注“不是作者原文”。语义试点纳入了新片段时需刷新索引。

“Zotero 批注”可按文字或题名筛选，每页 50 条，可另存为独立阅读笔记。源记录本次未返回时保留旧快照并标记，其失效检索片段会移除；原因可能是删除或 API 不再提供，不能直接断言已删除。另存笔记不被同步覆盖。每条摘录和评论最多保留 20000 字符、100 个标签，超限会提示；超过阅读笔记长度的批注需分段整理，不静默截短笔记。

PDF 许可目录只控制本机文件读取。即使 PDF 缺失或没有配置许可目录，API 返回的书目、笔记及批注文字仍可导入；文件访问仍受原目录许可约束。

本轮依据 [Zotero Local API](https://www.zotero.org/support/dev/web_api/v3/local_api)、官方[批注支持修复](https://github.com/zotero/zotero/pull/4337)和[批注格式测试](https://github.com/zotero/zotero/blob/main/test/tests/annotationsTest.js)适配。较旧 API 可能不返回批注，空列表不能证明库中没有批注。JSON/CSL 导出仍为原有书目兼容入口，本版批注功能使用 Local API，不把导出的独立批注冒充普通文献。当前机器 Zotero 未连接，未实导个人库；测试使用合成 API 与合成 PDF。

## 六维文献对照

1. 在检索结果或候选文献片段点击“加入文献对照”。每张表选择 2–6 篇不同文献，合计 2–8 个片段；每段保存最多 1800 字符，正文总计最多 12000 字符。
2. 命名并创建表。研究问题、理论视角、数据与对象、研究方法、主要发现、局限与适用范围六个维度分别填写；每格最多 2000 字，可勾选该篇所属的来源编号。没有依据时标记“材料未提供”。
3. 人工核对后勾选“本人已核对”。修改文字或出处会取消该格核对标记。保存使用版本检查，旧页面不能静默覆盖新表。来源在同步或删除后不自动改写单元格；保留创建时快照，重新打开表时核验来源、禁用失效页链接并提示。停留在已打开页面时不会实时刷新来源状态；AI 发送前仍会重新核验。
4. 可归档、恢复或导出为 Markdown / Excel 可读 CSV，均附来源快照。CSV 为 UTF-8 BOM，防止以公式起始的内容直接成为 Excel 公式；Markdown 把内容按文字处理。导出不是完整资料库备份。

已保存列表展示最近 200 张，资料在原 SQLite 数据库内；升级快照自动包含批注、对照表、来源和核对状态。原文缺失后仍可读表和导出。对照篮和未保存编辑只在当前窗口，软件内升级会等待处理这些内容。

## 可选 AI 提取

打开已保存表，展开 AI 提取，选择已有连接、填写比较重点并预览完整提示及发送材料。只发送这张表已选片段和书目信息，不发送手工单元格、其他文献或 PDF 文件。表、原文或 AI 连接变化时需重新预览。每份预览十分钟内有效，一次使用，不自动重试付费请求。

AI 返回的文献列、六个维度、每格文字及来源编号会进行结构检查。未知编号、跨文献引用、缺少维度、重复 JSON 键或无出处归纳会被拒绝；没有证据必须填写“材料未提供”。达到输出上限时不保存半张表，可减少文献数或到 AI 连接设置提高输出上限后再试。编号正确不证明论断正确。

结果先显示为未保存草稿。点击另存会创建一张独立的“AI 草稿”表，原表不变，所有核对标记为未核对。保存草稿需在生成后十分钟内操作。请逐格检查后再用于研究写作；本轮未使用真实付费账号验证模型质量。密钥与费用说明沿用 [AI 使用说明](ai.md)。
