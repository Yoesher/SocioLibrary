# 0.11.0 · 圆点图谱与自选期刊

参考 [Obsidian 官方图谱说明](https://obsidian.md/help/Plugins/Graph%2Bview) 与其官方帮助仓库的 [图谱示例](https://github.com/obsidianmd/obsidian-help/blob/master/en/Attachments/obsidian-graph-view.png)，采用小实心圆点、细连线、侧边标题和选中关系高亮。独立实现，没有复制其程序代码或打包其图片。

## 使用

- 圆点大小随相邻文献数量缓慢增加；所有界面风格统一使用圆点。
- 选中文献显示轻量光环，相关连线高亮，其余内容淡化；拖动固定使用轻量底环。
- 标题自动避让彼此及其他圆点。缩小时优先显示核心文献，放大后逐步出现更多标题；悬停显示完整题名，侧栏保留作者、年份及关系依据。
- 在“显示选项”中调整圆点大小，或将“标题密度”改为“全部显示”。这些探索选项只在当前打开期间保留。
- 小圆点与标题在常用缩放范围内维持可读尺寸；进一步缩小时保留整体轮廓。
- 浅色、墨夜和高对比配色分别适配画布、圆点和线条。

动态舒展、原位展开、拖动固定、返回/前进、来源筛选和阅读跳转沿用 0.10.0。每视图最多 80 篇；不把自动线索当作真实引文或结论一致的证明。

## 升级

安装程序和研究数据分开存放。覆盖安装沿用原有库、设置、本机模型、批注、笔记与比较表；首次启动新版本会先建立升级快照。不要将单独 EXE 从完整程序目录中移走。

## 返回按钮修复

三个界面风格的页头返回键统一为 32 × 32 像素的小图标按钮，不叠加主题的通用按钮内边距。Material 模式不再显示挤占标题的大圆圈；不可返回时保留位置并淡化。

## 自选期刊接入

在“期刊动态 → 添加期刊”选择接入方式。已有卡片可“修改来源”“暂停”“恢复订阅”；编辑已有订阅时保留原刊名，新刊请通过“添加期刊”建立。最多 50 种。

| 方式 | 填写内容 | 验证与范围 |
| --- | --- | --- |
| 官网 RSS / Atom | 期刊名称、公开 HTTPS 订阅地址；必要时填写频道中的英文刊名 | 检查真实 XML 订阅格式、频道刊名、公开网络地址；普通主页不可用。只覆盖频道当前条目。 |
| Crossref | 期刊名称、1 至 2 个 ISSN | 校验 ISSN 并向官方 `/journals/{issn}` 确认实际刊名；更新按索引日期回查。无需密钥，未收录期刊无法使用。 |
| OpenAlex | 期刊名称、ISSN；本机环境变量 `OPENALEX_API_KEY` | 确认来源身份；更新使用发表日期，晚收录旧文可能漏查。密钥不进入表单、订阅 URL 或公开仓库。 |
| 恢复内置官网来源 | 原有已接通期刊在“修改来源”中选择 | 恢复软件已支持的官网适配器；未接通期刊不会因此自动启用。 |

**可操作示例：** 添加 `American Sociological Review`，方式选 `Crossref · ISSN`，填写 `0003-1224`，点击“验证并保存”。确认返回的来源刊名一致后，点击“立即检查”。该 ISSN 的期刊身份已在本次开发中联网验证；书目覆盖和数量随数据库更新改变。

RSS 地址应来自出版机构明确提供的 RSS、Atom 或目录订阅链接，不猜测官网路径，不使用机构登录 Cookie、私有认证链接或抓取付费正文。若频道刊名是英文，可在“频道中的刊名”填写官网英文名称。

订阅配置写入本机研究库，重开和覆盖升级后继承；失败验证不会覆盖原设置。暂停保留已经入库的文献。保存只检查身份/订阅格式，实际入库请点“立即检查”。书目按 DOI 或既有严格匹配规则去重。

桌面版在启动时按月判断是否需要检查；关闭期间不运行。GitHub Actions 使用仓库中的公开配置，不会自动同步本机自选订阅或读取本机密钥。需要云端定时发现时，另行维护 `config/public-journals.toml` 的公开刊名、ISSN 和来源配置，密钥放 GitHub Secrets。

原有四刊继续使用官网来源；《社会学评论》《人口学刊》《中国社会科学》在提供有效来源并验证前保持待接入。

参考：[Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)、[OpenAlex 身份验证](https://docs.openalex.org/how-to-use-the-api/rate-limits-and-authentication)。
